\section*{Data and code availability}
The implementation, the experiment scripts, the per-run result records and the scripts that generate every table and figure of this paper are available at \url{https://github.com/vinhqdang/explainable_GNN_financial_fraud}. The Elliptic dataset is available from its publishers \citep{weber2019anti}. T-Finance is distributed with GADBench \citep{tang2023gadbench}. The synthetic benchmark is generated by \texttt{rtxgnn/synthetic.py}.
